# Telegram-бот: переезд во Вьетнам и гид по Нячангу

Бот помогает пользователям из России подготовиться к переезду во Вьетнам, разобраться с первыми шагами после приезда и пользоваться большим справочником по Нячангу. Интерфейс построен на кнопках: пользователь выбирает раздел, получает текст, а также фото или видео, если они добавлены к выбранной теме.

Контент хранится в `content/guide.json`, поэтому его можно редактировать двумя способами:

- через файлы репозитория;
- через Telegram-команды владельца бота.

## Возможности

- Главное меню и вложенные разделы через inline-кнопки.
- Отправка текста, изображений и видео для каждого раздела.
- JSON-справочник с понятной древовидной структурой.
- Перезагрузка контента без перезапуска процесса: `/reload_content`.
- Панель владельца: `/admin`.
- Быстрая замена текста раздела: `/settext`.
- Проверка доступа к админ-командам по `ADMIN_TELEGRAM_ID`.
- Dockerfile для запуска в контейнере.

## Быстрый старт

1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
2. Узнайте свой Telegram ID, например через [@userinfobot](https://t.me/userinfobot).
3. Установите зависимости:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

4. Настройте переменные окружения:

```bash
cp .env.example .env
export BOT_TOKEN="123456:token-from-botfather"
export ADMIN_TELEGRAM_ID="123456789"
export CONTENT_FILE="content/guide.json"
export MEDIA_ROOT="media"
```

5. Запустите бота:

```bash
python -m nyachang_bot
```

## Запуск через Docker

```bash
docker build -t nyachang-guide-bot .
docker run --env-file .env -v "$PWD/content:/app/content" -v "$PWD/media:/app/media" nyachang-guide-bot
```

Подключение `content` и `media` как volume позволяет менять справочник и файлы медиа без пересборки образа.

## Структура контента

Основной файл: `content/guide.json`.

```json
{
  "title": "Переезд во Вьетнам и жизнь в Нячанге",
  "welcome": "Текст главного меню",
  "items": [
    {
      "id": "relocation",
      "title": "Переезд из России",
      "body": "Описание раздела",
      "media": [
        {
          "type": "photo",
          "path": "relocation/checklist.jpg",
          "caption": "Чек-лист перед вылетом"
        }
      ],
      "children": []
    }
  ]
}
```

Правила:

- `id` должен быть уникальным, длиной до 40 символов.
- В `id` разрешены латинские строчные буквы, цифры, `.`, `_`, `-`.
- `children` содержит вложенные разделы.
- `media` может быть пустым массивом.
- Поддерживаемые типы медиа: `photo`, `video`.
- Пути в `media.path` указываются относительно `MEDIA_ROOT`, по умолчанию это папка `media`.

Пример структуры медиа:

```text
media/
  relocation/
    checklist.jpg
  city-guide/
    transport.mp4
```

## Команды пользователя

- `/start` - открыть главное меню.
- `/help` - показать подсказку.
- `/cancel` - отменить текущее действие.

## Команды владельца

Команды ниже доступны только пользователю с Telegram ID из `ADMIN_TELEGRAM_ID`.

- `/admin` - открыть панель редактирования.
- `/reload_content` - перечитать `content/guide.json` после правок в репозитории.
- `/content_ids` - показать ID всех разделов.
- `/settext ID` + новый текст со следующей строки - быстро заменить текст раздела.

Пример:

```text
/settext city-guide.mobile
Новый текст про связь и мобильный интернет в Нячанге.
```

Через `/admin` можно выбрать раздел кнопками, нажать "Изменить текст" и отправить новый полный текст следующим сообщением.
