Pokemon vs Dota TD
==================

БЫСТРЫЙ ЗАПУСК (Windows)
------------------------
1. Дважды щёлкните PokemonDotaTD.exe
   (если файла нет — см. «Собрать EXE» ниже)

2. В игре: Start Level 1


СОБРАТЬ EXE (один раз, если exe ещё нет)
----------------------------------------
1. Установите Python 3.10+ с https://www.python.org/
   (галочка «Add Python to PATH»)

2. Дважды щёлкните build_windows.bat в этой папке

3. На рабочем столе появится/обновится PokemonDotaTD.exe


ЗАПУСК БЕЗ EXE (через Python)
------------------------------
Откройте cmd в этой папке:

  pip install -r requirements.txt
  python main.py


УПРАВЛЕНИЕ
----------
ЛКМ — поставить/выбрать башню
P — режим установки
U — улучшение
ESC — выход
